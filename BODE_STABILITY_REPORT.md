# Q4 Local Bode Stability Analysis

## Purpose

The implemented aircraft is nonlinear, mode-switched and gain-scheduled.  It also
contains saturation, Comfort Guard, altitude-safety override, wind/gust models
and a time-varying nacelle schedule.  A single global LTI Bode model would
therefore be misleading.

The Q4 frequency-domain verification uses **local reduced-order loop models at
fixed operating points**.  Each model is derived directly from the controller
gains, rigid-body inertia and actuator time constants already used by the running
simulator.  Transition itself remains verified by the nonlinear time-domain
regression tests.

## Bode channels

### 1. Hover altitude

The implemented hover controller is

`v_z,ref = K_x e_h`

`a_z,cmd = K_v (v_z,ref - v_z) + K_i integral(e_h)`

For a locally constant altitude reference, `-v_z = d(e_h)/dt`, giving the
PID-equivalent controller

`C_h(s) = K_v s + K_v K_x + K_i/s`

and the reduced-order rotor-borne plant

`P_h(s) = 1 / [s^2 (tau_m s + 1)]`.

Current values are `K_x=0.32`, `K_v=1.25`, `K_i=0.08`, `tau_m=0.12 s`.

### 2. Cruise airspeed

The forward-speed control law is

`a_x,cmd = K_V (V_ref - V)`

with `K_V=0.85`.  Around wing-borne straight cruise the forward-propulsion
response is represented by rotor lag followed by integration from acceleration
to speed:

`P_V(s) = 1 / [s (tau_m s + 1)]`.

### 3. Pitch-attitude loop

The implemented attitude controller is PID-equivalent in local pitch error:

`C_theta(s) = K_d s + K_p + K_i/s`.

The local rigid-body plant is

`P_theta(s) = 1 / [I_yy s^2 (tau_a s + 1)]`.

The hover endpoint uses the rotor/motor lag `tau_a=tau_m=0.12 s`; the cruise
endpoint uses the elevator actuator lag `tau_a=0.10 s`.  The controller values are
`K_p=55`, `K_d=55`, `K_i=1.8`, `I_yy=26 kg m^2`.

### 4. Cruise cross-track loop

The route controller uses cross-track position error to generate lateral speed
reference, and lateral-speed error to generate acceleration.  Locally this is
another PID-equivalent position loop.  Its plant contains the **closed inner roll
attitude loop** followed by two lateral kinematic integrations.  This retains the
implemented roll inertia, attitude gains and aileron actuator lag rather than
assuming instantaneous bank response.

## Results

The reproducible values below are generated by `examples/run_bode_analysis.py`
and are regression-tested in `tests/test_stability_analysis.py`.

| Local loop | Closed-loop stable | Phase margin | Gain crossover | Closed-loop bandwidth | Peak closed-loop magnitude |
|---|---:|---:|---:|---:|---:|
| Hover altitude | Yes | about 66.4 deg | about 1.227 rad/s | about 1.769 rad/s | about 2.42 dB |
| Cruise airspeed | Yes | about 84.2 deg | about 0.846 rad/s | about 0.945 rad/s | about 0.00 dB |
| Pitch attitude - hover | Yes | about 50.7 deg | about 2.228 rad/s | about 3.633 rad/s | about 2.87 dB |
| Pitch attitude - cruise | Yes | about 53.2 deg | about 2.247 rad/s | about 3.577 rad/s | about 2.70 dB |
| Cruise cross-track | Yes | about 56.2 deg | about 1.231 rad/s | about 2.359 rad/s | about 2.19 dB |

For this project an engineering interpretation of phase margin is used:

- >=60 deg: strong local robustness
- 45-60 deg: good
- 30-45 deg: moderate
- <30 deg: low

This classification is a design heuristic, **not a certification requirement**.
The more fundamental local-stability check is that all closed-loop poles remain
in the left-half plane.

## Interpretation

### Hover altitude

The hover-altitude loop has a phase margin of roughly 66 deg and a bandwidth of
roughly 1.77 rad/s (0.28 Hz).  It therefore has meaningful phase tolerance while
remaining substantially slower than the inner attitude loop.  That separation is
desirable for the cascaded architecture: attitude/thrust response should settle
faster than the outer altitude loop.

### Cruise airspeed

The cruise-speed loop is the most conservative of the analysed loops, with an
approximately 84 deg phase margin and no meaningful closed-loop resonant peak.
Its approximately 0.95 rad/s (0.15 Hz) bandwidth explains why forward-speed
changes are intentionally much slower than attitude changes.

### Pitch attitude

Pitch phase margin is approximately 51 deg in hover and 53 deg in cruise.  The
endpoint change from rotor-moment to elevator-dominated actuation does not move
the local loop close to instability.  Closed-loop resonant peaks remain below
3 dB in both endpoint approximations.

### Cruise cross-track

The route-following loop has approximately 56 deg phase margin after including
the closed inner roll loop and aileron actuator lag.  This supports the use of
cross-track feedback under the tested gust cases without assuming instantaneous
roll response.

## Relation to the urban-wind and passenger-comfort factors from Q3

Bode analysis answers the **local small-signal robustness** question, while the
existing nonlinear regressions answer the finite-amplitude urban-disturbance and
comfort-supervisor questions.

### Urban wind / gust KPIs

- minimum altitude / maximum altitude deviation
- cross-track error
- recovery time
- body-rate response
- local altitude / cross-track phase margin and bandwidth

The Bode result shows that the nominal altitude and cross-track loops have
positive, useful phase margin.  The severe/repeated-gust simulations are still
required because the wind scenarios can drive aerodynamic nonlinearities,
actuator limits and safety override outside the local Bode assumptions.

### Passenger-comfort KPIs

- peak and RMS measured acceleration
- peak and RMS measured jerk
- ISO-2631-style weighted RMS acceleration
- duration above the selected comfort target
- commanded acceleration / jerk versus measured response

Comfort Guard is a nonlinear command envelope.  For sufficiently small
perturbations the envelope is inactive and therefore does **not** change the
nominal Bode curves.  When the envelope, tilt cap or altitude-safety override is
active, the appropriate verification method is the nonlinear mission response.

## What Q4 can claim

The current evidence supports the following statement:

> Local reduced-order Bode models at the hover and cruise operating points are
> closed-loop stable.  All analysed channels have phase margin greater than
> 45 deg and closed-loop resonant peaks below approximately 3 dB.  Nonlinear
> transition, strong gust and comfort/safety switching are not treated as one
> global LTI system; their stability and performance are verified separately by
> the existing time-domain regression scenarios.

This is deliberately narrower than claiming global nonlinear stability.
